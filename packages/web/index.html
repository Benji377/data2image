Data2Image

GitHub

Drop any file to convert it into a PNG image. Drop a .d2i.png to get the original back.

How it works

  • Encode: Wraps any file into a valid PNG image. The original data is stored in PNG metadata chunks, making it a regular image file that can be shared, uploaded, or stored anywhere images are accepted.
  • Decode: Extracts the original file from a .d2i.png image, restoring it to its original format and name.
  • Auto Mode: Automatically detects .d2i.png files and decodes them, encodes everything else.
